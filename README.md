# AI QA and Delivery Assistant: course repository

The working repository for **AI for Product Owners and QA** (ElateIQ). This copy holds Day 8. Later days will be added to it as the course reaches them.

## Start (once)
1. On this repository's GitHub page: **Use this template**, then **Create a new repository** (your own copy).
2. In your copy: **Code**, **Codespaces**, **Create codespace on main**. The first build takes a while.
3. When asked for the secret `GEMINI_API_KEY`, paste your key from Google AI Studio. You can also add it later under GitHub **Settings**, **Codespaces**, **Secrets**.
4. Stop your Codespace after each session (Codespaces page, **Stop**) to save your free hours.
